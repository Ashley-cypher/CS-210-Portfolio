# CS-210 Portfolio

## Airgead Banking Project

### Project Summary
Money grows over time, but seeing how it happens makes a difference. For this project, I built a C++ program that shows how savings can grow with interest, both with and without monthly deposits. I wanted the results to be easy to understand, even for someone who doesn't know much about investing.

### What I Did Well
One thing I'm proud of is how everything started coming together. I worked on keeping my code organized while making sure the calculations gave the right results. Seeing a program I built actually work is one of my favorite parts of learning to code.

### What I Would Improve
There's always room to make something better. I would add more checks for incorrect entries and make the program easier for someone to use. I also want to keep improving how I organize my code so future changes won't be as difficult.

### Challenges and What I Learned
The interest calculations and loops gave me the most trouble. Sometimes fixing one thing meant going back and checking something else. I learned to slow down, look at what the code was actually doing, and test it instead of guessing. Visual Studio, zyBooks, and my course resources helped me work through those problems. More than anything, I learned that patience matters in programming.

### Skills I'll Carry Forward
This project gave me more practice with C++, functions, loops, classes, and user input. But it also taught me something bigger: how to work through a problem when the answer isn't obvious. That's something I can carry into future classes and eventually into a career in technology.

### Keeping My Code Organized
I separated my program into different files and worked on using names that made sense. I wanted someone else to be able to look at my code and understand what was happening without having to figure everything out from scratch. As I keep learning, I want to write programs that aren't just functional but are also easy to maintain and improve.
